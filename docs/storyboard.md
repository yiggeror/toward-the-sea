# 《去看海吧》There is a bigger world — 分镜 / Shot list

目标时长约 7.5–8 分钟，16:9，24 fps。无对白。时间线：
城市（雨后夜）→ 黎明出城 → 森林（早晨阳光）→ 丘陵（午后起风、暴雨）→ 夜宿（废弃公交站）→
荒原（次日上午）→ 雪原（白昼）→ 海岬（黎明前后，强风）→ 看见大海（日出）→ 海边沙滩（清晨）。

明信片状态（wear 0→1）：城市 0（全新）→ 森林 0.05（沾了点水）→ 暴雨后 0.35（水渍、卷边）→
夜里 0.45（一道折痕）→ 荒原 0.6（灰尘、缺一角）→ 雪原 0.75（褪色、边缘起毛）→ 海岬 0.9（很旧）→ 被风吹走。

明信片画面与结尾真实海景是同一个构图函数 `drawSeaView()`：海平线约在画面 42% 高度，右侧海岬伸入海中，
海岬顶端一座白色灯塔，左侧远处一座小岛，天空两三朵云。明信片是白天的水彩配色；结尾是日出配色。
