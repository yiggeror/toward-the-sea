# 《去看海吧》导演版 v2 — 剧本与分镜

目标约 4 分 40 秒，16:9，24 fps，无对白。v1 的问题：几乎全是横向侧面全景，猫在不同背景前重复走路，
剪辑平铺直叙，大段只有环境声，情绪只在结尾出现。v2 的原则：

1. **每个镜头都有任务**：建立、反应、揭示、笑点、情绪。不为"交代路途"而拍走路。
2. **镜头在猫的视线高度**：近景、特写、插入镜头、主观镜头、过肩、俯拍、仰拍；猫在纵深里朝镜头/远处走（近大远小）；全景只用于"渺小"与"辽阔"。
3. **剪辑跟着音乐**：配乐贯穿全片，蒙太奇按小节剪；静默是刻意的（失去明信片之后）。
4. **一条贯穿的线**：明信片。它像一阵风一样来（拍在脸上），在旅途中被磨旧，在海角被风带走，最后被海浪送回——画已经被海水洗掉了，而真正的海就在眼前。

音乐（全部程序合成）：M1 雨夜钢琴（稀疏） · M2 明信片动机（钟琴 A–D–E–F#） · M3 奔跑（拨弦固定音型 112 bpm） ·
M4 旅程主题（96 bpm，马林巴、拨弦、钢琴、轻打击；溪水处停一拍，暴雨转小调，梦境转慢） ·
M5 海角（风中固定音型→追逐→骤停） · M6 看见海（主题完整奏响） · M7 海边（轻快变奏→终止和弦）。
