自检记录与已知不足

已经逐帧检查过的

  • 每个片段都抽取连续 12–24 帧做成联系表，确认轮廓每张都在变、支撑脚在地面刻度上不滑动。
  • 落脚：着地的爪子固定在世界坐标里，身体越过它移动；起步时由控制器安排先迈哪条腿，停步时补收尾步。
  • 接触：身体轮廓不会穿进地面，尾巴坐下时沿地面躺平；跳上台子时每只爪子按自己脚下的高度着地。
  • 遮挡：远侧两条腿永远在身体后面并压暗，近侧腿在前；舔毛时前爪提到脸前。
  • 次级运动：尾巴、耳朵、胡须是对身体运动的弹簧响应，可随意跳帧，不依赖播放顺序。

还不够好的地方（下一步继续改）

  • 奔跑（袭步）已经有腾空伸展和收拢两个极端，但腾空的高度和“停顿感”还可以更强。
  • 睡觉已经能团起来、尾巴绕到身前，但身体轮廓仍偏“面包形”，没有设定图那么圆。
  • 转身在最收拢的一张画上翻面（加了拖影），中间还缺一张真正的正面过渡画。
  • 甩水的水珠已经有了，身体本身的甩动幅度还偏小，毛的抖动可以更夸张。
  • 还没有做光照：夜景的轮廓光、环境反光会在场景阶段加入。
  • 正面、背面坐姿是单独绘制的画稿，与侧面骨骼之间靠切换画稿衔接。
  • 纯侧脸时五官挤在脸前，最好看的是 3/4 侧脸，影片里会尽量避开纯侧脸。
